연동정보 관리
Oracle 직접조회와 PowerCLI vCenter 자동수집 정보를 등록하며 다음 일일 배치부터 적용됩니다
⚠️ 운영 기본은 Oracle 직접조회와 PowerCLI vCenter 직접수집입니다. FILE_ONLY는 장애분석용 보조 모드이며, 작업 스케줄러는 서버에서 1회 등록합니다.
🗄️ Oracle ITSM
Oracle 설정 저장과 연결 테스트는 vCenter 설정과 완전히 분리되어 실행됩니다.
서비스명은 Oracle 서버명이나 IP가 아니라 DBA가 제공하는 SERVICE_NAME입니다. 일반적으로 tnsnames.ora의 SERVICE_NAME 값이며, 예시는 ORCLPDB1 형태입니다.

🔎 Oracle 자산 테이블 찾기
접속한 DB에서 조회 계정이 볼 수 있는 테이블/뷰를 확인하고 자산 원본으로 지정합니다.
자산 조회가 ORA-00942(테이블 없음)로 실패하면 여기에서 실제 테이블을 찾아 자산 원본으로 적용하세요. 선택한 테이블의 컬럼에 맞춰 조회 SQL이 자동 생성되며, 없는 컬럼은 NULL로 채워 필수 컬럼 검증을 통과시킵니다.
현재 자산 원본: 미지정
소유자테이블/뷰유형행수(통계)설명선택
테이블 목록 조회 또는 자산 테이블 추천을 실행하세요.
🛰️ vCenter 연결 관리
vCenter마다 접속 주소와 조회 계정을 등록합니다. PowerCLI 실행경로와 파일 보관경로는 서버 내부 설정을 사용합니다.
기본 입력은 표시명, vCenter IP/FQDN, 조회계정, 비밀번호입니다. 저장 전에도 연결 테스트를 실행할 수 있으며 TCP 443, PowerCLI 모듈, 로그인, VM 조회까지 확인합니다.
